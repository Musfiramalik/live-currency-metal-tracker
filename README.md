# Live Currency & Metal Price Tracker

A real-time Python CLI dashboard that tracks live currency exchange rates and precious metal prices using APIs, with automatic updates and a clean terminal interface.

---

## 🚀 Features
- Live currency exchange rates (USD, EUR, SAR)
- Real-time updates every 5 seconds
- Clean CLI dashboard using Rich library
- PKR conversion support
- Simple and lightweight Python project

---

## 🛠️ Technologies Used
- Python
- requests (API handling)
- rich (CLI table UI)
- time (refresh control)
